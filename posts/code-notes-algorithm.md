## 数组 {#array}

### 421. 数组中两个数的最大异或值 {#array-max-xor}

一句话：把数字按二进制位存入字典树，逐位「反着找」，让高位异或结果尽量为 1。

- 异或相当于按位「不进位加法」，每一位独立运算；要让 num[i] ^ num[j] 最大，优先保证二进制高位的异或结果为 1。
- 做法：遍历数组时先把前 i-1 个数存入字典树，再在字典树中查找与当前数异或最大的匹配——每一位 0 找 1、1 找 0，保留过程中的最大值；遍历完即得答案。
- 时间复杂度 O(n·L)，L 为数字的二进制位数。

### 1863. 找出所有子集的异或总和再求和 {#array-subset-xor-sum}

一句话：枚举全部 2^n 个子集，把每个子集内部的异或值累加，暴力可直接过。

- 解法一（DFS 递归）：每个位置的元素都有「加入」与「不加入」子集两个分支；i == nums.length 时结束，把累计异或结果加入总和。
- 解法二（二进制枚举）：n 个数共有 2^n 个子集，用 n 位二进制数表示每位取或不取（1 取 0 不取）；枚举每个二进制数，为 1 的位参与异或，最后累加所有子集结果。

## 链表 {#list}

### 142. 环形链表 II：判环与找环入口 {#list-cycle}

一句话：快慢指针判环，相遇后从 head 再发一个与 slow 同速的指针，再次相遇处即环入口。

- 判环（同环形链表 I）：fast 一次走两个结点、slow 一次走一个，相等则有环；fast 相对 slow 每次接近一个结点，不会错过。
- 找入口证明：设链表头到环入口距离 a、环长 b。相遇时 f = 2s 且 f = s + nb（fast 多走 n 圈），解得 s = nb；而走到入口共需 a + nb 步，slow 已走 nb、再走 a 步即到入口——所以从 head 出发的指针与 slow 同速前进，恰在入口相遇。
- 时间 O(n)，空间 O(1)。

### 双指针方法论 {#list-two-pointers}

一句话：双指针不是数据结构而是操作方法，用两个指针在一个 for 循环内完成两个 for 的工作，把 O(n²) 降为 O(n)，数组、链表、字符串通用。

- 反转字符串：首尾对撞指针，交换后向中间走，左指针不小于右指针时截止。
- 移除元素 / 替换空格：快慢指针——快指针在前探测，等于目标值时慢指针停住，由后元素覆盖前元素实现「删除」（数组存储连续，覆盖即移除）；替换空格则先按空格数扩容，左右指针分别从原串和扩充串最右端出发，右指针根据左指针信息行动。
- 反转链表：结构决定用 cur 与 pre 两指针回指实现反转；回指前必须先保存 cur.next，否则后继丢失；循环至 cur == null，返回 pre 作为新头。
- 移除链表元素：引入虚拟头结点统一操作，避免头结点单独处理——new 一个不存值的 dummy 并令 dummy.next = head。

## 哈希表 {#hash}

### 哈希函数 {#hash-function}

一句话：哈希函数是根据关键字 key 经函数关系得到元素存储位置的映射。

| 方法 | 做法 | 适用场景 |
| --- | --- | --- |
| 直接定址法 | H(key) = a·key + b（a、b 为常数） | 关键字分布基本连续 |
| 除留余数法 | H(key) = key % p（p 不大于表长 m） | 整数型关键字 |
| 叠加法 | 关键字分段后取叠加和（舍进位） | 位数多且各位分布均匀 |
| 随机数法 | 取随机函数值作哈希值 | 关键字长度不等（如小数） |

### 哈希冲突 {#hash-collision}

一句话：不同关键字经同一哈希函数得到相同地址即哈希冲突（碰撞），用开放地址或链表化解。

- 开放地址法（前提：表长不小于所存元素总数）：冲突后按某一次序找下一个空闲单元放入。线性探查——从冲突单元依次查看下一个单元，到表尾再回表首；平方探查——从冲突单元依次加 1²、2²、3²…n² 直到遇到空位；双散列函数探查——两个散列函数 s1、s2，s2 取 1~m-1 间与 m 互素的数作步长，适合表长事先无法确定的情况，平均查找长度较短。
- 分离链接法：哈希值相同的元素构成链表，表槽存链表头；Java 中链表长度超过 8 转红黑树、少于 6 退回链表；缺点是指针需额外空间。

## 树 {#tree}

### 树的遍历 {#tree-traversal}

一句话：前中后序（VLR、LVR、LRV）是人为为半线性的二叉树定义次序，本质是把半线性结构转换成线性结构。

- 数组、链表自带次序，遍历只是正向或反向；二叉树没有明显次序，需人为定义，选定前中后序即规定了「结点与左右孩子」的处理顺序。
- 整体思维：把一棵二叉树看成根、左子树、右子树三个大结点，按所选次序整体排序；局部再按同一规则递归排序，最后把局部与整体同序组合即得遍历序列。

（原 PDF 此处为三种遍历结果图示）

### 红黑树与 AVL 树 {#tree-rb-avl}

一句话：两者都是自平衡二叉查找树，红黑树是弱平衡（在 AVL 基础上提出的折中），以更少旋转换取增删查均衡的性能。

红黑树五条性质（保证最长路径不超过最短路径的两倍，近似平衡）：每个结点非红即黑；根结点是黑色；每个叶结点（树尾端 NULL 指针）都是黑色；红色结点的子结点必须为黑色；任一结点到叶 NULL 指针的每条路径都包含相同数目的黑色结点。

| 对比项 | AVL 树 | 红黑树 |
| --- | --- | --- |
| 平衡程度 | 高度平衡，左右子树高度差不超过 1 | 弱平衡，最长路径不超过最短的两倍 |
| 插入/删除 | 频繁插删引起频繁 rebalance，效率下降 | 插入最多两次旋转、删除最多三次旋转 |
| 复杂度 | O(log n) | 查找、插入、删除均 O(log n) 且性能稳定 |
| 适用场景 | 查询远多于修改 | 搜索、插入、删除操作较多的情况 |
| 典型应用 | —— | STL 的 set、map 底层实现 |

### 字典树（Trie） {#tree-trie}

一句话：利用字符串的公共前缀组织存储，最大限度减少无谓的字符串比较。

- 性质：根结点不保存字符，其余每个结点保存一个字符；从根到某结点路径上字符连接起来即该结点对应的字符串；每个结点的所有子结点字符互不相同。
- 应用：统计、排序、保存大量字符串；数组篇 421 题的最大异或值用的就是二进制字典树思想。

### 108. 将有序数组转换为二叉搜索树 {#tree-sorted-array-to-bst}

一句话：每次取区间中点作根并递归构造左右子树，与 106. 从中序与后序遍历序列构造二叉树思路基本一致，只是切分点固定为中点。

- 步骤：区间为空返回 null（终止条件）→ 切分点 index = left + (right - left) / 2 → 新建根结点 TreeNode(nums[index])，区间只剩一个元素直接返回 → 按区间不变量分割左右子区间 → 递归构造。
- 易错点：坚持区间不变量——[左闭右开) 与 [左闭右闭] 均能过，左闭右闭更友好。

### 538. 把二叉搜索树转换为累加树 {#tree-bst-to-gst}

一句话：按「右 → 根 → 左」的反中序遍历一遍二叉树，边遍历边累加改写结点值。

- 只遍历不增删 BST 结点，递归函数无需返回值；用 sum 记录当前结点之前所有结点值之和，当前结点值更新为原值加 sum；也可用栈迭代实现，顺序仍是右/根/左。

## 回溯 {#backtrack}

### 组合问题与剪枝 {#backtrack-combination}

一句话：同一集合的组合用 startIndex 记录每层递归起始位置避免重复；求和型回溯在进入下一层前剪枝。

- 同一集合的组合问题：需要 startIndex 记录横向遍历（for 循环）的起始位置。
- 元素可重复选时下一层起始位置仍为 i，不可重复选时为 i + 1；求和型回溯要剪枝：if (sum > target) return，或先判断 sum + candidates[i] <= target 不成立则不进入下一层。

### 分割问题 {#backtrack-partition}

一句话：分割实质也是组合问题，切割的方式就是选择的起始位置。

- 关键是截取子串：s.substr(startIndex, i - startIndex + 1)；本层从 startIndex 切到 i，下一层从 i + 1 继续，回溯时撤销当前切分。

### 排列与去重 {#backtrack-permutation}

一句话：排列不用 startIndex 而用 used 标记数组；含重复元素时按「同层去重、同枝可用」处理。

- 排列问题：用标记数组记录元素是否已使用，做选择时 used[i] = true，撤销时 used[i] = false。
- 数组含重复元素、要求不出现重复组合（树层结点可重复，同一层不允许重复）：前提是先升序排序保证相同元素相邻（关键）；used[i-1] == true 表示同一树枝用过、used[i-1] == false 表示同一树层用过；去重一定与前一个元素比较，核心代码：if (i > 0 && candidates[i-1] == candidates[i] && used[i-1] == false) continue。

### 回溯通用模板 {#backtrack-template}

一句话：回溯的骨架就是「做选择 → 递归 → 撤销选择」。

```java
void backtrack(参数) {
    if (满足结束条件) {
        result.add(路径);
        return;
    }
    for (选择 : 本层可选列表) {
        处理结点;            // 做选择
        backtrack(下一层);    // 递归
        回溯, 撤销处理;       // 撤销选择
    }
}
```

## 贪心 {#greedy}

### 1864. 构成交替字符串需要的最小交换次数 {#greedy-min-swap}

一句话：按字符串长度分奇偶讨论，统计奇数位上的错配字符个数即为最小交换次数。

- 统计四个量：num1、num0（全串中 1/0 的个数），odd1、odd0（奇数位上 1/0 的个数）；特判：num1 与 num0 相差大于 1 时无法构成交替串，返回 -1。
- 偶数长度有两种目标串：1010…（1 开头，奇数位都应为 1，交换次数为 odd0）与 0101…（0 开头，奇数位都应为 0，交换次数为 odd1），取最小值。
- 奇数长度只有一种可行目标：1 开头必然 num1 > num0，答案为 odd0；0 开头必然 num0 > num1，答案为 odd1。

## 动态规划 {#dp}

### 方法论：dp 五步曲 {#dp-methodology}

一句话：动态规划中每一个状态一定由上一个状态推导而来（贪心没有状态推导，只从局部直接选最优），做题固定走五步。

dp 五步曲：确定 dp 数组及下标含义 → 确定递推公式 → dp 数组初始化 → 确定遍历顺序 → 举例推导 dp 数组（打印验证）。

- 边界 case（如 509 题的 n <= 1）放在函数开头单独处理，防止 dp 数组下标越界。
- debug：打印 dp 数组与手推模拟值对比——一致说明问题出在五步曲的公式、初始化、顺序；不一致说明代码细节有 bug；动笔前先把状态转移在 dp 数组上完整模拟一遍。

### 初识 DP：基础题 {#dp-basic}

一句话：从斐波那契到路径计数，体会五步曲的完整套用。

- 509. 斐波那契数：dp[i] = dp[i-1] + dp[i-2]；dp[0] = 0、dp[1] = 1；从左到右。
- 70. 爬楼梯：与斐波那契同构，dp[i] = dp[i-1] + dp[i-2]。不能按「前两阶分别跳一步」计数——那样会先到前一阶，仍等价于从前一阶跳一步，方案重复。
- 746. 使用最小花费爬楼梯：dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])；dp[0] = dp[1] = 0。易错：顶峰在最后一个元素之后，不能直接 return dp[n-1]，应为 min(dp[n-1] + cost[n-1], dp[n-2] + cost[n-2])。
- 62. 不同路径：dp[i][j] = dp[i-1][j] + dp[i][j-1]（只能从正上或正左过来）；首行首列全 1；从上到下、从左到右。
- 63. 不同路径 II：与 62 基本一致，区别两点——障碍处 dp[i][j] = 0；初始化首行/首列一旦遇障碍就停止赋 1（其后均不可达）。
- 343. 整数拆分：dp[i] = max(dp[i], max(j * (i - j), j * dp[i - j]))，两种来源是「j 与 i-j 直接相乘」和「j 乘继续拆分的 dp[i-j]」；dp[2] = 1（dp[0]、dp[1] 无意义）。
- 96. 不同的二叉搜索树：以 j 为根时左右子树方案数相乘，dp[i] += dp[j-1] * dp[i-j]；dp[0] = 1。

### 背包问题 {#dp-knapsack}

一句话：背包问题最重要的就是两点——递推公式和遍历顺序；面试常考 01 背包（每件选一次）与完全背包（每件无限选）。

- 322. 零钱兑换（完全背包求最少硬币数）：dp[j] = min(dp[j], dp[j - coins[i]] + 1)；dp[0] = 0、其余正无穷；若 dp[j - coins[i]] 仍是初始值（INT_MAX）要跳过；求最少个数时内外层顺序无关。与 518. 零钱兑换 II 的三点区别：递推公式（min + 1 vs += 求和）、初始化（其余正无穷 vs dp[0] = 1）、遍历顺序（518 求组合数必须外层物品、内层背包）。
- 279. 完全平方数（完全背包）：与 322 基本一致，物品是 i*i；dp[j] = min(dp[j], dp[j - i*i] + 1)；满足 j >= i*i 且 dp[j - i*i] != MAX 才更新；内外层顺序无关。
- 爬楼梯进阶（一次可上 1~m 阶）：转化为完全背包求排列数——每次上的阶数是可重复使用的物品，楼顶台阶数是背包容量；(1, 2) 与 (2, 1) 是不同方法，故求排列数；dp[j] += dp[j - i]，dp[0] = 1 其余为 0；必须外层背包、内层物品。

| 对比项 | 01 背包 | 完全背包 |
| --- | --- | --- |
| 物品件数 | 每件最多选一次 | 每件可选无限次 |
| 一维 dp 内层（背包）遍历 | 必须倒序，保证每件只取一次 | 正序 |
| 一维 dp 循环嵌套 | 必须先物品后背包 | 纯完全背包（求最值）时无关 |
| 求组合数（顺序无关） | 外层物品、内层背包 | 外层物品、内层背包 |
| 求排列数（顺序有关） | —— | 外层背包、内层物品 |

两类题型的递推公式：

- 求最大/最小价值：dp[j] = max 或 min(dp[j], dp[j - weight[i]] + value[i])；求最大/最小物品个数：dp[j] = max 或 min(dp[j], dp[j - coins[i]] + 1)。
- 初始化——求最少：dp[0] = 0、其余正无穷；求最多：全 0（coins 全为正时；含负数则负元素对应位置初始化为负无穷）。
- 求装满背包的方案数：dp[j] += dp[j - nums[i]]，组合数与排列数的遍历顺序见上表。

一维 dp 遍历顺序模板：

```java
// 01 背包：外层物品，内层容量倒序（保证每件只用一次）
for (int i = 0; i < n; i++)
    for (int j = bagSize; j >= weight[i]; j--)
        dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
// 完全背包求组合数：外层物品，内层容量正序
for (int i = 0; i < n; i++)
    for (int j = coins[i]; j <= amount; j++)
        dp[j] += dp[j - coins[i]];
```

### 子序列问题 {#dp-subsequence}

一句话：先分清「连续（子数组/子串）」还是「不连续（子序列）」，再定义 dp 数组。

- 674. 最长连续递增序列：与 300. 最长递增子序列 的区别是要求连续，反而更简单——一层 for 比较 nums[i] > nums[i-1]，满足则 dp[i] = dp[i-1] + 1；全部初始化为 1；返回 dp 数组最大值而非 dp[n-1]。
- 392. 判断子序列：dp[i][j] 表示 s 前 i 个与 t 前 j 个字符的相同子序列长度；相等时 dp[i][j] = dp[i-1][j-1] + 1，不等时 dp[i][j] = dp[i][j-1]（相当于删掉 t[j-1] 继续比较）；首行首列全 0；最终判断 dp[m][n] == m。
- 115. 不同的子序列：dp[i][j] 表示 s 前 i 个字符中出现 t 前 j 个字符的子序列个数；相等时 dp[i][j] = dp[i-1][j-1] + dp[i-1][j]（用当前字符匹配 + 不用，两种情况之和）；不等时 dp[i][j] = dp[i-1][j]（删掉 s[i-1]）；初始化 dp[i][0] = 1、dp[0][j] = 0。
- 516. 最长回文子序列：dp[i][j] 表示区间 [i, j] 内最长回文子序列长度；首尾相等时 dp[i][j] = dp[i+1][j-1] + 2，不等时 dp[i][j] = max(dp[i+1][j], dp[i][j-1])；dp[i][i] = 1；dp[i][j] 需从左下方推导，遍历从下到上、从左到右。

### 股票问题 {#dp-stock}

一句话：股票系列的通用技巧是把每天拆成「持有 / 卖出」两种状态做状态机 DP。

714. 买卖股票的最佳时机含手续费（可多笔交易、每笔付一次手续费，与 122. 买卖股票的最佳时机 II 很像，唯一区别是卖出时额外减手续费）：

- dp[i][0]：第 i 天持有股票的最大现金 = max(dp[i-1][0]（不买，保持持有）, dp[i-1][1] - prices[i]（前一天卖出的基础上今天买入）)。
- dp[i][1]：第 i 天卖出股票的最大现金 = max(dp[i-1][1]（不卖，保持卖出）, dp[i-1][0] + prices[i] - fee（前一天买入的基础上今天卖出并扣手续费）)。
- 初始化：dp[0][0] = -prices[0]，dp[0][1] = 0；从前到后遍历。

### 时间序列模型 {#dp-time-series}

一句话：序列中每个元素可视为「一天」，今天的状态只取决于昨天（无后效性）。

- 思路：确定 dp[i][j]（第 i 轮的第 j 种状态）→ 画状态（转移）图，将 dp[i][j] 与前一轮状态 dp[i-1][*] 建立关系得到转移方程 → 确定基础值后编码。
- 代表题目：LC 487. 最大连续 1 的个数 II、打家劫舍系列、股票系列（打家劫舍 III 进一步运用树形 DP）；树形 DP 可类比后序遍历——明确当前层结果如何计算、需要向父结点传递什么，可从二叉树路径问题入手理解。

### 区间 DP {#dp-interval}

一句话：状态从小区间推向大区间，分「固定分成 K 段」与「对整个序列操作取最优」两种模型。

- 模型一：序列明确分割成 K 个连续区间，求区间的最优性质。相关题：LC 813. 最大平均和的分组、LC 1278. 分割回文串 III、LC 410. 分割数组的最大值、LC 1335. 工作计划的最低难度。
- 模型二：对整个序列经操作取最优——按区间大小依次枚举所有子区间的结果，整个区间的最优从子区间最优逐步结算。相关题：664. 奇怪的打印机、1547. 切棍子的最小成本、1682. 最长回文子序列 II（plus）、1690. 石子游戏 VII、1745. 回文串分割 IV、1000. 合并石头的最低成本。这类题偏难，模型不万能，仍需按题展开。

664. 奇怪的打印机：

- dp[i][j] 为 [i, j] 区间的最小打印次数；s[i] == s[j] 时打印 s[i] 可顺便打印 s[j]（中间可被覆盖），dp[i][j] = dp[i][j-1]；s[i] != s[j] 时分为 [i, k] 与 [k+1, j] 两段（k 取 [i, j)），dp[i][j] = min(dp[i][k] + dp[k+1][j])。
- 初始化 dp[i][i] = 1；遍历 i 从大到小、j 从小到大——dp[i][j] 依赖 dp[i][k] 与 dp[k+1][j]，只有这样才能保证依赖的子区间已计算（无后效性）。

### BFS {#dp-bfs}

一句话：广度优先搜索的重点在实现细节与问题抽象。

1. 是否访问的标识一定要处理好，否则会陷入死循环；
2. 根据题意选择邻接矩阵或邻接表存图（偏向邻接表）；和背包模型一样，要学会把原问题抽象成 BFS 模型。

### 编辑距离 {#dp-edit-distance}

- 这类题给定两个字符串；一个新颖的点是 dp 数组用 dp[i][j] 表征下标 i-1、j-1 相关的信息（下标整体偏移一位，初始化更简洁）。

### 回文串 {#dp-palindrome}

一句话：回文问题把一个字符串从两个维度展开成二维 dp，只有右上三角参与推导。

- 先区分求回文子序列（不连续）还是回文子串（连续）；二维图推断时左下角不参与，只有右上角参与判断；两个维度当作一个闭区间，天生满足 i <= j。
- 回文子串：dp 设 bool，判断区间内是否回文；回文子序列：dp 设 int，存区间内最长回文子序列长度，初始化 i == j 时为 1、其余 0。
- 遍历顺序：子串 i 从 s.size()-1 到 0、j 从 i 到 s.size()-1；子序列 j 从 i+1 开始——i == j 已在初始化赋值，后续推理正是基于它展开。

## 其他算法 {#misc}

### 经典面试算法 {#misc-classic}

一句话：递归逆序栈、猫狗队列、有序链表公共部分、二叉树非递归遍历、斐波那契多解法，是五类高频手撕题。

1. 仅用递归函数和栈操作逆序一个栈：栈依次压入 1~5（顶到底为 5 4 3 2 1），要求转置后顶到底为 1 2 3 4 5，不能用其他数据结构。两个递归配合——第一个递归深入栈中，取得并移除栈底元素且不改变其余元素顺序；第二个递归把取出的元素放回，push 要在递归返回后再执行。总结：想改变容器元素顺序又不用额外数据结构，可借助递归函数的返回值安排操作。
2. 猫狗队列：实现支持 add、pollAll、pollDog、pollCat 的狗猫队列结构；考查实现特殊数据结构与特殊功能算法设计的能力。
3. 打印两个有序链表的公共部分：循环比较两个指针的数值，两指针都不能为空，值小的推进，相等就记录并两个指针都推进。
4. 递归与非递归实现二叉树先/中/后序遍历：递归只需调整「处理结点」与「递归左右子结点」的顺序；非递归用栈模拟，统一三种遍历的难点在中序——访问顺序与处理顺序不一致。解决：用空结点作标记，取得栈中非空结点时依次压入「该结点 + 空标记」表示只是访问；取到空标记时再弹出下一个非空元素处理。注意树的空子结点不能压栈，否则算法失效。
5. 斐波那契数列的递归与动态规划：暴力递归 return f(n-1) + f(n-2)，O(2^n)；顺序遍历从左到右计算到第 n 项，O(n) 时间（一维数组空间 O(n)，可滚动优化）；矩阵乘法——F(n) 是二阶递推数列，可用 2×2 状态矩阵的 N 次方表示，把 N 次方转化为位的形式（一个矩阵保存累乘结果，一个矩阵计算 1、2、4、8…次方，记录每一位对应的矩阵乘法结果），时间复杂度 O(log n)。

### 大数据处理问题 {#misc-bigdata}

一句话：核心策略是「大而化小、分而治之」——哈希分片到小文件，再用 hash_map / 堆统计。

公共数据问题：

- 两个各 2T 的文件（按行存放字符串）找公共字符串 / 各 50 亿 url（64 字节每个、内存 4G）找公共 url：按内存限制划分 N 个小文件尽量均匀（url 例约为 1000 个、每个约 300M）→ 遍历 A 对每行做哈希，按哈希值映射到 A1~AN；B 用同一哈希函数处理得 B1~BN（保证小文件一一对应）→ 逐对比较 <Ai, Bi>（不对应的小文件不可能有相同数据），数据量已足够小，可装入 hashmap 对比。
- 1000 万有重字符串去重：哈希映射到不同文件 → 逐个文件用 hash_set 查重 → 对所有文件的 hash_set 求交集。若多个数据哈希后挤进同一个小文件，更换哈希函数重新分片。

TOP N 问题：

- 通用策略：哈希映射拆成小文件 → 每个小文件用 hash_map 统计出现频率最大的数据 → 所有文件的最大数据放入大根堆 → 从堆中取 N 个元素。
- 上亿有重数据统计前 N：内存存不下时——哈希分小文件 → hash_map 统计各文件出现最多的并记录次数 → 对各文件最多的建大根堆，重复 N 次「取走堆顶并重建堆」；内存存得下时直接 hash_map 统计并建大根堆。
- 海量日志提取某日访问百度次数最多的 IP：IP % 1000 映射到 1000 个小文件（相同 IP 必进同一文件，不会出现拆散后累加变大的情况）→ 分 1000 次在内存用 map 统计各文件频率最大的 IP → 对这 1000 个 IP 建大根堆。1000 万查询串统计最热门 10 个同理。
- 1G 文件、每行一个不超过 16 字节的词、内存限制 1M、返回频数最高前 100：单词 % 5000 存入 5000 个小文件（平均约 200K）→ 超过 1M 的文件继续分割直到小于 200K → 用 map 统计各词频率 → 堆排序或归并排序取前 100。

分布式 TOP N 问题：

- 数据分布在 100 台电脑（各数据只出现在一台机器）：先在独立机器得到前十——放得下内存直接堆排序，放不下则「哈希分块 → map 统计 → 归总堆排」；再把 100 台机器的 TOP10 组合起来堆排序。
- 同一元素可出现在不同机器：先遍历所有数据重新哈希取模，使同一元素只出现在单独一台电脑，再按上法统计每台 TOP10 后汇总。

### A* 算法 {#misc-astar}

一句话：带启发函数的最短路搜索，用 F = G + H 评估每个格子，每轮只扩展 F 值最小的结点，解决地图上带障碍的起点到终点最短路问题。

- Open 表存储当前能够到达的结点；Close 表存储已经到达过的结点。
- 公式 F = G + H——G：从起始结点走到当前结点已花费的步数；H：不考虑障碍时从当前结点到终点的预估步数；F：对 G、H 的综合评估，即路径若经过此格最终所需步数的预估。

算法步骤：

1. 将起点放入 Open 表；
2. 在 Open 表中找出 F 值最小的结点作为当前结点，移出 Open 表、加入 Close 表；
3. 扩展当前结点四周可达的结点，不在 Open 表和 Close 表中的，计算 F 值后加入 Open 表，并把当前结点设为这些扩展结点的父结点；遇到障碍物或已在 Close 表中的结点直接跳过。
4. Open 表非空且未找到终点时重复第 2、3 步，每轮都选 F 值最小的结点检查扩展。

实现要点（Java）：Open 表用优先队列实现小根堆（队首自动是 F 最小者），Close 表用普通数组；优先队列不能迭代遍历，另设 Exist 表收集两表出现过的所有结点用于查重；Node 类含 x、y、F、G、H、Father，实现 Comparable 按 F 比较，H 用与终点坐标的曼哈顿距离计算；地图外围加一圈墙作辅助边界，判断越界只需检查地图值是否为 -1。

主循环骨架：

```java
while (!Open.isEmpty()) {
    Node cur = Open.poll();               // 取 F 最小结点出队
    Close.add(cur);
    for (Node next : extend(cur)) {       // 扩展四周合法邻结点
        if (next 是终点) { next.init_node(cur, end); return next; }
        if (!is_exist(next)) {
            next.init_node(cur, end);     // 设父结点并计算 G/H/F
            Open.add(next); Exist.add(next);
        }
    }
}
```

找到终点后沿结点的 Father 指针逐级回溯即得路径。（原 PDF 此处含完整 Java 实现与过程动图）

### 堆排序 {#misc-heapsort}

一句话：先自底向上建堆，再循环「堆顶元素换到集合尾部、调整堆产生新堆顶」。

1. 把无序数组构建成二叉堆（从最后一个非叶子结点开始向前逐个下沉调整）；

### 最短路径问题 {#misc-shortest-path}

一句话：多源用 Floyd（DP 思想），单源有 Bellman-Ford、SPFA、Dijkstra（贪心 + 优先队列）。

多源最短路径（Floyd）：

- 求图中任意两顶点间的最短路径；本质是 DP——每轮循环更新「经过前 k 个结点时 i 到 j 的最短路径」，即比较当前最短与 i→k + k→j 能否更短。
- 核心：dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])，三重循环 k、i、j；初始化 dist 为 int_max、i→i 填 0；时间复杂度 O(n³)，本质是暴搜但能搜出全部两点间最短路。

单源最短路径：

- Bellman-Ford：一维 dist[] 存各点到起点距离，最短路形如 S → P1 → P2 → … → D。暴力破解：第一遍求得一步可达点的结果，第二遍得到两步可达点……只要图中不存在环，有限轮遍历后必得全部最短路径；对所有边反复松弛，时间复杂度 O(nm)。
- SPFA（队列优化的 Bellman-Ford）：每轮真正可能被更新的，只有「刚被更新过的点所能直达的点」。借助队列：对出队的点更新它能到达的点，把不在队列中的更新点入队，直到队空。要点——只让当前点能到达的点入队；已在队列的点不重复入队；一条边未被更新则其终点不入队。时间复杂度不稳定，最坏 O(nm)。
- Dijkstra（要求无负边，基于贪心）：起点 dist 置 0 并更新直达点；因无负边，未确定点中 dist 最小者的 dist 已是最终结果；以它为跳板继续更新，每轮确定一个点直至全部确定。取最近的点用优先队列（小根堆）；一个点被访问前队列里存有它被更新的整个历史，按路径从小到大出队，小路径出队时该结点已处理过，大路径出队直接跳过。堆优化后 O(m log n)。
- 打印路径：建 pre 数组，更新 dist 时同步记录父结点；结果是一棵树，逐级溯源路径唯一。

| 算法 | 适用 | 核心思想 | 负权边 | 复杂度 |
| --- | --- | --- | --- | --- |
| Floyd | 多源 | DP，逐个引入中转点 k | 可（无负环） | O(n³) |
| Bellman-Ford | 单源 | 对所有边反复暴力松弛 | 可 | O(nm) |
| SPFA | 单源 | 队列优化，只松弛可能被更新的点 | 可 | 不稳定，最坏 O(nm) |
| Dijkstra | 单源 | 贪心 + 优先队列，逐个确定最近点 | 不可 | O(m log n) |
